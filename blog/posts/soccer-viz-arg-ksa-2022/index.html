Function setup

Code 
def get_pre_shot_passes(passes_df, shots_df):
    """Get passes made within 15 seconds of a shot"""

    pre_shot = [] # empty list to collect results

    for _, shot in shots_df.iterrows():
        #looping through every shot one at a time

        shot_time = shot['minute'] * 60 + shot['second']
        # converting shot time to total seconds

        window = passes_df[
            (passes_df['minute'] * 60 + passes_df['second'])
            .between(shot_time - 15, shot_time)
        
        #convert every pass time to total seconds
        # then find passes that happened within the 15 second window BEFORE the shot
        ]
        pre_shot.append(window)
        # add to results list

    return pd.concat(pre_shot).drop_duplicates() if pre_shot else pd.DataFrame()
        # combine all results
        # remove duplicates
        # return empty dataframe if nothing is found 

arg_pre_shot = get_pre_shot_passes(arg_passes, arg_shots)
ksa_pre_shot = get_pre_shot_passes(ksa_passes, ksa_shots)

1. Pass Map Viz - Buildup to the Shot

Code 
fig, axes = plt.subplots(1, 2, figsize=(16, 8))
fig.patch.set_facecolor('#ffffff')
fig.suptitle('Pass Buildup to Shot (Within 15 Seconds)',
             color='black', fontsize=22, y=1.04, fontweight = 'bold')

for ax, passes_df, team, color in zip(
    axes,
    [arg_pre_shot, ksa_pre_shot],
    ["Argentina", "Saudi Arabia"],
    ['#75AADB', '#00b100']
):
    pitch = Pitch(
        pitch_type='statsbomb',
        pitch_color='#fafafa',
        line_color='#cccccc',
        line_zorder=2
    )
    pitch.draw(ax=ax)

    # complete passes
    complete = passes_df[passes_df['outcome_name'].isna()]
    if not complete.empty:
        pitch.arrows(
            complete.x, complete.y,
            complete.end_x, complete.end_y,
            ax=ax,
            color=color,
            width=2,
            headwidth=4,
            alpha=0.8,
            label='Complete'
        )

    # incomplete passes
    incomplete = passes_df[passes_df['outcome_name'].notna()]
    if not incomplete.empty:
        pitch.arrows(
            incomplete.x, incomplete.y,
            incomplete.end_x, incomplete.end_y,
            ax=ax,
            color='#000000',
            width=1.5,
            headwidth=3,
            alpha=0.9,
            label='Incomplete'
        )

    ax.set_title(team, color='black', fontsize=13, pad=10)
    ax.legend(facecolor='#fafafa', labelcolor='black',
              loc='upper left', fontsize=13,
              markerscale=1.5,
              framealpha=0.8
              )

plt.tight_layout()
plt.savefig('images/pass_map.png', dpi=150,
            bbox_inches='tight', facecolor='#fafafa')
plt.show()

Why Track passes 15 seconds before a shot?

This type of tracking reveals the precise off ball movements, spacing and defensive fractures that create scoring opportunities, rather than just analyzing the final action. If the coach only looks at shots, then they’re reacting only to the outcome. Looking at passes 15 seconds before a shot can give an idea of spatial patterns before looking at the shot map

🟦 Argentina Takeaways

1. The high volume of passes show that Argentina dominated possession
2. Short and quick arrows are clustered together meaning 
a lot of tight passing was carried out
3. Argentina controlled the ball and recycled possession heavily in the opponent's half 
creating a sustained attacking pressure

🟩 Saudi Takeways

1. Saudi Arabia sat deeper, played fewer passes and relied on direct balls when they 
played forward
